# Upapada

Calculates the Jaimini Upapada Lagna and its related chart data from
planetary placements.

Use `calculate` for the typed Effect result.

The Upapada is the plain Arudha Pada of the twelfth house (see the Arudha Pada module
and ADR-0004), so it carries the same caveat: the classical adjustment for a result
that lands on the source sign or the seventh from it is not applied.
