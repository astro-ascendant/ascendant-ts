# Jaimini

This directory contains the package's Jaimini astrology calculations.

Each submodule is independently exported from the package root:

- [`argala`](./argala/): planetary intervention
- [`arudha-pada`](./arudha-pada/): arudha padas
- [`chara-karakas`](./chara-karakas/): Chara Karakas
- [`karakamsha`](./karakamsha/): Karakamsha
- [`rashi-drishti`](./rashi-drishti/): sign aspects
- [`upapada`](./upapada/): Upapada Lagna

The calculators consume chart placements and return typed Effect results.
