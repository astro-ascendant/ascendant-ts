# Select the named calculation rule table

Chara Karakas use the fixed order Atmakaraka, Amatyakaraka, Bhratrikaraka, Matrikaraka, Putrakaraka, Gnatikaraka, and Darakaraka. Rashi Drishti uses movable-to-non-adjacent-fixed, fixed-to-non-adjacent-movable, and dual-to-other-dual relationships; Argala uses supporting positions 2, 4, and 11, obstructing positions 12, 10, and 3, secondary positions 5 and 9, and reverses the same counting for an explicit Ketu reference. These calculations accept any valid positional evidence without imposing natal meaning at runtime.
