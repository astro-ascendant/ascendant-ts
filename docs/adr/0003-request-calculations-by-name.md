# Request calculations by name

Jaimini identifies an astrological school and the provenance of several distinct calculations, not a calculation requested as a whole. Public operations therefore expose directly named calculation surfaces at their natural subject, accept only the evidence that calculation requires, return only their named results with compact supporting evidence, and keep supporting calculations internal unless separately requested. Each operation rejects missing or duplicate required evidence through a typed failure, and each result records structured provenance containing its school, calculation-specific method, and version rather than an umbrella Jaimini method; references that change a calculation's semantics, such as an ordinary Sign versus reversed Ketu Argala, are explicit inputs. Callers compose the typed operations through Effect rather than a school-wide service or string selector; the composition may share pure internal work but succeeds only when every requested result can be produced. A school-wide operation, mandatory result bundle, unrelated chart requirement, or silent partial result would misrepresent user intent.
