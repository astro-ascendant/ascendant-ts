Which layers provide which services, and which modules require them.

  • Solid arrows are the default wiring; dashed arrows are alternatives or optional.
  • Dasha, Jaimini and SAV need no services. They are pure functions over the Placements that Chart.generate produces.
  • BunServices.layer appears only in the docs' example runtime layer, so its link to SwissephLayer is inferred.
